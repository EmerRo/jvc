📖 Instrucciones
  1. Abre una terminal en C:\xampp\htdocs\jvc
  2. Ejecuta: php server/websocket-server.php
  3. Haz clic en "Conectar" arriba
  4. Prueba enviar mensajes con los botones
  5. Abre esta página en otra pestaña para ver las notificaciones en tiempo real

Tip: Para ver cómo funciona en tu aplicación, abre tu proyecto en http://localhost/tu-proyecto y usa la consola del navegador: window.JVCWebSocket
